# jsonic

**JSON Data Serializer and Deserializer**

Jsonic is a high-level abstraction for JSON serialization and deserialization, built as a thin wrapper over Zig's `std.json` module with compile-time type checks and code generation.

## Platform Support

Fully cross-platform.

## Dependency

No external dependencies.
